# Soplang 3.3.0 implementation milestone

Status: implemented in the development source. Distribution and publication
have not been scheduled.

## Files and data

- Read and write UTF-8 text, binary files, and bounded file-handle chunks.
  Explicit handles support line reads, seeking, flushing, and closing. Open
  handles belong to one execution context and close when that context ends.
- Inspect and manage files, directories, and paths. Atomic replacement is
  available for files on the same filesystem.
- Parse and write JSON and CSV; encode URL components and Base64; use regular
  expressions, UTC timestamps, arguments, environment variables, and child
  processes with captured output.

See the [file](../language/file-handles.md),
[filesystem](../language/filesystem.md), and
[structured data](../language/json.md) references.

## Network access

- Make synchronous HTTP and HTTPS requests with bounded redirects, response
  sizes, and timeouts. HTTPS verifies the server certificate.
- Serve bounded JSON HTTP requests one at a time, with route parameters,
  predictable 404 and 500 responses, and explicit shutdown.
- Use DNS, TCP, UDP, and a WebSocket client.

See the [HTTP client](../language/http.md),
[HTTP server](../language/http-server.md), and
[networking](../language/networking.md) references.

The HTTP server and socket APIs are synchronous. Concurrent handlers,
streaming request bodies, WebSocket servers, and graceful draining of active
connections belong to 3.6.
