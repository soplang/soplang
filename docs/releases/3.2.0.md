# Soplang 3.2.0 implementation milestone

Status: language foundations implemented locally. Distribution builds, native
platform executables, and publication are pending. The published release remains
3.0.1; the [3.1 runtime milestone](3.1.0.md) is also implemented locally.

## Iteration and collection loops

- Direct iteration over lists, ranges, Unicode string scalars, and object keys,
  values, and entries.
- User-defined iterator protocols on classes and objects through `wareeg` and
  `xiga`, shared with native cursors and lazy adapters.
- `tirso`, `lamaane`, and exact-length row bindings in `kuceli` loops.

See [iteration](../language/iteration.md).

## Function arguments

- Default parameters evaluated at call time with lexical captures and fresh
  mutable literals.
- Variadic positional rest parameters and named arguments with `**` keyword
  collectors.
- Static and runtime callback signature validation before collection methods run.

See [function arguments](../language/function-arguments.md).

## Data types

- Insertion-ordered hash [sets](../language/sets.md) and [typed sets](../language/typed-sets.md).
- Immutable [tuples](../language/tuples.md) with positional annotations.
- Compact [byte arrays](../language/bytes.md) with strict UTF-8 and checked mutation.
- [Optional and union](../language/optional-union-types.md) annotations on variables,
  parameters, and returns.
- [Typed lists and objects](../language/typed-collections.md) with shared nested contracts.
- Immutable structured `khalad` errors with codes, causes, traces, and optional
  structured catches (carried forward from the 3.1 runtime work).

## Collection method libraries

Both compiler backends implement the planned operations for core value kinds:

| Kind | Documentation |
| --- | --- |
| Text | [Unicode text methods](../language/text-methods.md) |
| List | [List methods](../language/list-methods.md) |
| Object | [Object methods](../language/object-methods.md) |
| Number | [Numeric functions](../language/numeric-functions.md) |

Numeric coverage includes logarithms, radian trigonometry with optional inverse
mode, two-argument angles, named constants, clamping with exact integer extrema,
and context-local seeded random streams that do not advance on invalid calls.

## Verification and limits

See [3.2 verification](../testing/LANGUAGE_3_2.md) for commands, per-stage evidence,
and the final local gate (`269` debug tests with `--skip test_aot`, `14` diagnostic
and example host tests, and `94` optimized tests in the numeric release selection).

Shared fixtures run through Cranelift JIT and LLVM at optimization levels 0 and 2.
Cross-target `cargo check` passes for Windows x64 and macOS ARM64; running packaged
binaries on those platforms remains a distribution gate.

These changes do not implement 3.1 [strings and wide calls](../releases/3.1.0.md#strings-and-calls)
items still listed on the roadmap (escaped-string ABI extensions), 3.3 file and network
I/O, 3.4 projects and packages, or later tooling and concurrency work.

The [Somali wording supplement](../language/runtime-error-wording.md) records public
names and diagnostics for terminology review. Documentation remains in English;
user-facing language diagnostics remain in Somali.
